# Quadratic formula

The discriminant is $\Delta = b^2 - 4ac$ and it decides the roots.

$$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$

Standard LaTeX delimiters must render too:

\[ ax^2 + bx + c = 0 \]

Inline standard form \( y = mx + c \) is the same idea.
