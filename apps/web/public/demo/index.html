How a PDF appears on a web page — two shapes

Reference pages (not features) for the three shapes we discussed. Both render the same tiny sample.pdf; the difference is only in the src the page gives the iframe. Inspect each with DevTools → Elements.

  • Shape 1 — a real PDF embedded with <iframe> (src ends in .pdf; AskTree can already clip this)
  • Shape 2 — a PDF turned into a blob: URL (runtime-only; not in the page source)
  • Shape 3 — a canvas/image viewer (Baidu Wenku style): no PDF resource exists, so nothing to read. Not included.

Served by pnpm dev at /askTree/demo/. These are for reference: the extension does not clip embedded PDFs.
