Shape 2: a PDF turned into a blob: URL

Here the page fetches the PDF in JavaScript, wraps the bytes in a Blob, and hands the iframe an object URL. Many "export" and "preview" apps do exactly this. 

const bytes = await (await fetch("sample.pdf")).arrayBuffer();
const url = URL.createObjectURL(new Blob([bytes], { type: "application/pdf" }));
document.getElementById("viewer").src = url;

Open DevTools → Elements: the iframe's src is now blob:http://localhost:5173/… and it appears nowhere in the page source. This is the shape the S1 spike proved readable from a content script (read the src from the DOM, then fetch it in the page's origin).
