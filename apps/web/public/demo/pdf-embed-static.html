Shape 1: a real PDF embedded with <iframe>

This is the most common way a PDF appears on a web page: the page points straight at a PDF file. 

<iframe src="sample.pdf" type="application/pdf"></iframe>

Open DevTools → Elements and look at the iframe below: its src ends in .pdf. AskTree can clip this PDF today because the URL is a plain http(s) file the background can fetch.
