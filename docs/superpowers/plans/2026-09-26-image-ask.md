# Image Ask (Multimodal) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let a user paste or pick images, send them with a question to the model, and see them again on the answer node after reload.

**Architecture:** Images are carried on the edge (`Edge.images`) inside `TreeJSON`, and on the request as `AskOptions.images`; each provider maps them to its own request shape. `QuestionInputBar` owns attaching and clearing; `DualPanel` stores them on the edge, passes them to `ask`, and renders the stored images on the answer panel.

**Tech Stack:** TypeScript (strict), React 18, Vitest + Testing Library, Playwright, pnpm workspaces.

**Spec:** `docs/superpowers/specs/2026-09-26-multimodal-image-ask-design.md`

## Global Constraints

- `AskImage` is `{ mediaType: string; data: string }` with `data` base64 **without** a `data:` prefix.
- `Edge.images` and `AskOptions.images` are **optional**; absent means "no images", and with no images every request body must be **byte-for-byte what it is today**.
- No count or size limits on attached images (deliberate); provider errors pass through.
- Branch: `multimodal-ask` (stacked on `docx-import`).
- Run from `/home/whj/Repo/askTree`; Node via `export PATH="$HOME/.nvm/versions/node/v24.16.0/bin:$PATH"`.
- Rebuild core after core changes before web type-checks: `pnpm --filter @asktree/core build`.

- [ ] **Step 3: Implement `fileToAskImage`**

Create `apps/web/src/lib/image.ts`:

```ts
import type { AskImage } from "@asktree/core";

/** Read a File into an AskImage (base64, no data: prefix). */
export function fileToAskImage(file: File): Promise<AskImage> {
  return new Promise((resolve, reject) => {
    const reader = new FileReader();
    reader.onerror = () => reject(new Error(`Could not read "${file.name}"`));
    reader.onload = () => {
      const result = String(reader.result);
      const comma = result.indexOf(",");
      resolve({
        mediaType: file.type || "image/png",
        data: comma >= 0 ? result.slice(comma + 1) : result,
      });
    };
    reader.readAsDataURL(file);
  });
}
```
